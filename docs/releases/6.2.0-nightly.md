# Rhythm 6.2.0 Nightly

Development continues after the Stable 6.1.0 baseline.

- Gapless Playback prepares the next playlist item for automatic transitions.
  Crossfade follows the selected playback speed when scheduling an overlap.
- ReplayGain preserves peak polarity when boosting integer PCM and correctly
  handles the silence level of unsigned 8-bit audio.
- On Android 12L and later, **Settings → Playback → Allow system spatial audio**
  lets you choose whether Android can spatialize local music playback. Rhythm
  applies changes when playback stops so the current song can finish uninterrupted.
- Search a granted lyrics folder once per lookup, preserving custom filenames
  and the existing order of lyric formats.
- Preserve original library addition dates across verified file moves and MediaStore
  reindexing. Reused IDs, ambiguous recordings and a second copy of an existing file
  do not prove identity. Normal scans keep their existing scope and cache safeguards.
- Artist artwork uses distinct Unicode-safe cache identities and conservative
  legacy migration. Guest artists no longer inherit a host artist's generic folder
  portrait; saved audio artwork and FLAC verification remain separate.
- Create a new playlist with its selected song directly, without racing the
  asynchronous playlist list. Retain the ordered process-owned playlist writer.
- Resolve selected storage trees conservatively, preserve URI grants and colons
  in folder names, and show useful folder feedback. Failed opaque Downloads IDs
  do not expand to the whole Downloads directory. No automatic disk walker added.
- Correct repeat-one/all icons and defer the crossfade end-pause guard until a
  transition is near. Keep service-owned occurrence tokens and FIFO Play Next.
- Improve Dolby/Atmos/MPEG-H and multichannel codec labels. Bitrate does not prove
  lossy Atmos is lossless, and these labels do not claim physical output quality.
- Show custom AutoEQ profiles in preset selection and retain actual pinned profile
  bands. Keep deliberate bounded effect controls and the external DSP lifecycle.
- Use the active Library pager for refresh/scroll behavior and the adaptive
  notification interval editor. Home's retained six-hour/manual feed remains intact.

Native Music Assistant/Sendspin stays available. Larger upstream decoder-policy,
telemetry and queue-reorder rewrites are excluded where they would replace the
fork's stronger routing, queue identity or playback-rate handling.
