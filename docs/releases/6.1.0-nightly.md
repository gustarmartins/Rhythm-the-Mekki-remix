# Rhythm 6.1.0 Nightly

Music Assistant now connects through Rhythm Go's normal provider setup. Its
server library uses Rhythm's native browsing, search, album, playlist and player
screens. Native Sendspin audio is connected to Rhythm's Media3 session, lyrics,
Bluetooth metadata, audio focus and audio-effect lifecycle.

This development adds server queue controls, occurrence-safe duplicate songs,
ordered Play Next reconciliation and optional player/group/transfer controls.
Android 17's local-network permission is requested when connecting to a
self-hosted music server, including Jellyfin and Subsonic.

Cloud validation passes 365 application tests and 198 Sendspin tests. Munch's
native playback qualification is still pending after the phone restarted and
became unreachable during verification. These notes do not claim native listening
or physical Bluetooth/car acceptance.

Use a direct LAN, Tailscale or HTTPS URL. WebRTC Remote ID, offline downloads,
phone-local files mixed into server queues, and embedding edits into server
files remain unavailable. The server owns crossfade and queue continuation;
USB bit-perfect and legacy-car one-item MA queue views are not qualified.

Stable 6.0.0 remains separate and excludes Music Assistant.
See [integration details and verification status](https://github.com/gustarmartins/Rhythm-the-Mekki-remix/blob/main/docs/MUSIC_ASSISTANT_NATIVE.md).
