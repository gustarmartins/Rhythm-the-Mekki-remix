# Rhythm 6.1.0 Nightly

Development continues separately from the Music Assistant-free **6.0.0 Stable**.
Release names now use `MAJOR.MINOR.PATCH`, with `-nightly.N` for development
builds and one increasing Android version code shared by both channels.

This Nightly adds the first native Music Assistant catalog/control API adapters:
track metadata and lyrics, player discovery, queue occurrences, ordered appends,
paused-state-preserving transfers, volume and group membership commands.
Twenty-five regression tests cover these contracts and request failure behavior.

Real-server checks against Music Assistant 2.10.6 Stable found and fixed favorite
command compatibility, cold queue request timeouts, and preservation of the
server's separate resume position. FLAC/MP3 streams and a two-player group were
checked using muted, instrumented browser players and the native Kotlin adapters.

**These adapters are not yet connected to Rhythm's native library/player UI.**
The existing Music Assistant screen still uses the embedded server frontend.
Native Sendspin phone audio, the Media3 service connection, FIFO Play Next
reconciliation and WebRTC Remote ID support remain in development. This build
does not claim native Rhythm phone playback or physical synchronization validation.

See [native integration status and feature comparison](https://github.com/gustarmartins/Rhythm-the-Mekki-remix/blob/main/docs/MUSIC_ASSISTANT_NATIVE.md)
for the implemented layer and remaining work.
