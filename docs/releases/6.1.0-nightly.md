# Rhythm 6.1.0 Nightly

Home now has a listening-controls shortcut whose icon follows the active Bluetooth,
USB, wired-headphone or speaker output. Open lyric line width, update interval,
hold/scroll timing, text mode and display switches without digging through Settings.
Bluetooth profiles remain tied to the device selected when the editor opens.

Fresh setups enable lyrics and available integrations, prefer online lyrics, and
use the Expressive full player with the Rhythm mini-player. Ambient artwork and
its gentle zoom start enabled at 35% intensity. Existing preferences are preserved.
Library modification remains optional: setup offers Android media-management
access, and declining it does not prevent listening or displaying downloaded covers.

Mini-player artwork no longer runs a hidden shimmer after loading. Progress updates
are isolated from the rest of the card, and unused/background interpolation is
suspended. Physical-device performance qualification is ongoing; these changes do
not constitute a blanket 120 fps guarantee.


Music Assistant opens through Rhythm Go's native provider setup. Old direct
shortcuts now lead there too. The settings card puts **Open in Rhythm Go** first;
**Server administration** is a separate, clearly labeled web interface. Provider
setup navigation also works when Go mode is already active.

Music Assistant connects through Rhythm Go's normal provider setup. Its
server library uses Rhythm's native browsing, search, album, playlist and player
screens. Native Sendspin audio is connected to Rhythm's Media3 session, lyrics,
Bluetooth metadata, audio focus and audio-effect lifecycle.

This development adds server queue controls, occurrence-safe duplicate songs,
ordered Play Next reconciliation and optional player/group/transfer controls.
Android 17's local-network permission is requested when connecting to a
self-hosted music server, including Jellyfin and Subsonic.

Cloud validation passes 374 application tests and 198 Sendspin tests. The native
Android test passed on Munch using a real 1,827-track server library: catalog and
search, FLAC/MP3 playback, pause, seek, ordered Play Next, duplicate occurrences,
and lyric metadata without a playback restart. This also fixes position timing
and search waiting behind background artist-artwork downloads.

Physical listening, Bluetooth/car displays, group synchronization and Android
Auto acceptance remain separate from these automated results.

Use a direct LAN, Tailscale or HTTPS URL. WebRTC Remote ID, offline downloads,
phone-local files mixed into server queues, and embedding edits into server
files remain unavailable. The server owns crossfade and queue continuation;
USB bit-perfect and legacy-car one-item MA queue views are not qualified.

Stable 6.0.0 remains separate and excludes Music Assistant.
See [integration details and verification status](https://github.com/gustarmartins/Rhythm-the-Mekki-remix/blob/main/docs/MUSIC_ASSISTANT_NATIVE.md).
