# Rhythm 6.0.0 — Stable

This release brings the latest native Rhythm improvements together under a clean,
independently versioned fork release. **Music Assistant is excluded**: no embedded
workspace, service, sign-in storage or related settings are included in this APK.
Music Assistant development continues on the 6.1 Nightly line.

## What's new

- More reliable playback and queue restoration, including large queues, duplicate
  occurrences, FIFO Play Next and retained shuffle traversal after reopening.
- Output-device-aware Bluetooth lyric timing and compatibility profiles, with
  the service's full queue preserved behind constrained car displays.
- Improved local/embedded/online lyrics fallback and corrected Better Lyrics
  requests. Fresh installs enable media-display lyrics and supported online
  sources while existing users keep their explicit preferences.
- A new artwork-download choice after onboarding, with separate cover/motion
  preferences and metered-network controls. Existing preferences remain intact.
- Bounded background artwork/enrichment work, safer artwork handling and caches,
  and automatic battery-saver behavior.
- Streaming catalog improvements and search fixes: local mode no longer starts
  automatic streaming searches, and search state changes stay on the main thread.
- Clear release names, clean Stable/Nightly separation, and verified signed
  downloads through the in-app updater.

The app package and signing identity are unchanged; update in place to keep data.
Select **Settings → Updates → Stable**. This release has a higher Android build
number than the preceding Nightlies. Android may ask to confirm installation.

Release validation covers the full JVM regression suite, both release flavors,
release lint/R8 and APK identity/signature verification. Publication does not
claim new physical-car, listening or device-install acceptance.
