# Rhythm 6.1.0 — Stable

This release promotes the tested 6.1 Nightly feature set, based on Nightly 8701.
It retains the existing package, signing identity, library, playlists and settings.

- Home Discover keeps its album selection across tab changes and metadata updates.
  Pull to refresh updates Home from the loaded library, with a six-hour freshness
  window; it does not request a full device-library scan.
- Home recommendations use the configured optional Last.fm artist hints, matched
  to eligible songs on the device, with a local fallback when offline.
- The Rhythm mini-player gives its Wavy progress style room to render and honors
  the selected mini-player style and carousel auto-scroll settings.
- FIFO Play Next, duplicate queue occurrences, native shuffle and restoration,
  library continuation, search state and optional resume controls remain intact.
- Native Music Assistant catalog, server-owned queues/output controls and Sendspin
  phone playback are available through Rhythm Go. Server buffering remains
  separate from local-media failure handling; credentials stay out of backups.
- The 6.1 line includes safer bounded audio-effect controls, protected artwork
  matching/saves, asynchronous playlist persistence and local/synced lyric fixes,
  including explicit tempo/length headers for edited tracks.

This Stable baseline does not contain the subsequent upstream integration work.
Automated validation covers the complete JVM suite and both signed release
flavors, R8/lint-vital, package/version/signature and published asset hashes.
Bluetooth/car timing and every external server/device remain separate runtime
acceptance boundaries.

Choose **Settings → Updates → Stable**. Android may ask for installation
confirmation. Existing explicit channel preferences are preserved.
